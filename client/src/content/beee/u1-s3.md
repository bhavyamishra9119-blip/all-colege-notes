### 3. Superposition Theorem

#### 3.1 Statement, Applicability & Key Limitation

* **Statement:** In any linear, bilateral electrical network containing two or more independent sources, the resultant current through (or voltage across) any branch equals the algebraic sum of the individual currents (or voltages) produced by each independent source acting alone, while all other independent sources are deactivated.
* **Source Deactivation Rules:**
  * **Independent Voltage Source:** Replaced by a **Short Circuit** ($0\text{ V}$) (retain its internal series resistance if present).
  * **Independent Current Source:** Replaced by an **Open Circuit** ($0\text{ A}$) (retain its internal parallel resistance if present).
  * *Important Rule:* Dependent (controlled) sources are **NEVER** deactivated.
* **Critical Exam Limitation (The Power Rule):** Superposition applies **ONLY** to linear quantities (Voltage $V$ and Current $I$). It **CANNOT** be used to add power directly ($P = I^2 R \neq I_1^2 R + I_2^2 R$)! Always find total $I = I' \pm I''$ first, then calculate $P = I^2 R$.

<example title="Superposition Step-by-Step" level="medium">
A $20\text{ V}$ voltage source is in series with $R_1 = 4\,\Omega$, feeding a node connected to load $R_L = 4\,\Omega$ and a $3\text{ A}$ current source injecting upward into the node. Find downward load current $I_L$.
1. **Case 1 ($20\text{ V}$ active alone, open-circuit $3\text{ A}$ source):**
   $$I_L' = \frac{20}{4 + 4} = 2.5\text{ A}\text{ (downward)}$$
2. **Case 2 ($3\text{ A}$ active alone, short-circuit $20\text{ V}$ source):**
   By Current Divider between parallel $4\,\Omega$ and $4\,\Omega$:
   $$I_L'' = 3 \times \frac{4}{4 + 4} = 1.5\text{ A}\text{ (downward)}$$
3. **Total Superposition Current:**
   $$I_L = I_L' + I_L'' = 2.5 + 1.5 = 4.0\text{ A}\text{ (downward)}$$
</example>

### 4. Thevenin’s & Norton’s Theorems

#### 4.1 Thevenin’s Theorem (Series Voltage Equivalent)

* **Statement:** Any linear, bilateral two-terminal active DC network across load terminals A–B can be completely replaced by an equivalent circuit consisting of a single independent voltage source $V_{\text{th}}$ in series with an equivalent resistance $R_{\text{th}}$.
* **4-Step Solution Algorithm:**
  1. Remove load resistance $R_L$ across terminals A–B (leave A–B open-circuited).
  2. Compute open-circuit voltage across A–B: $V_{\text{th}} = V_{AB(\text{oc})}$.
  3. Deactivate all independent sources (Voltage $\to$ Short, Current $\to$ Open) and look into terminals A–B to compute $R_{\text{th}}$.
  4. Reconnect load $R_L$ to the equivalent circuit and compute load current:
  $$I_L = \frac{V_{\text{th}}}{R_{\text{th}} + R_L}$$

#### 4.2 Norton’s Theorem (Parallel Current Equivalent)

* **Statement:** Any linear, bilateral two-terminal active DC network across load terminals A–B can be completely replaced by an equivalent circuit consisting of a single independent current source $I_N$ in parallel with an equivalent resistance $R_N$.
* **Connection Between Thevenin and Norton:**
  $$I_N = \frac{V_{\text{th}}}{R_{\text{th}}} \qquad R_N = R_{\text{th}}$$
  $$I_L = I_N \times \frac{R_N}{R_N + R_L}$$

<example title="Thevenin & Norton on One Network" level="medium">
A $24\text{ V}$ source feeds series $R_1 = 6\,\Omega$ and parallel $R_2 = 3\,\Omega$ across terminals A–B, driving load $R_L = 4\,\Omega$.
1. Remove $R_L$ $\to$ Voltage divider for $V_{\text{th}}$:
   $$V_{\text{th}} = 24 \times \frac{3}{6 + 3} = 8\text{ V}$$
2. Short $24\text{ V}$ source $\to$ Parallel combination for $R_{\text{th}}$:
   $$R_{\text{th}} = 6 \parallel 3 = \frac{6 \times 3}{6 + 3} = 2\,\Omega$$
3. Load current via Thevenin:
   $$I_L = \frac{8}{2 + 4} = 1.33\text{ A}$$
4. Norton Equivalent Check:
   $$I_N = \frac{V_{\text{th}}}{R_{\text{th}}} = \frac{8}{2} = 4\text{ A}, \quad R_N = 2\,\Omega$$
   $$I_L = 4 \times \frac{2}{2 + 4} = 1.33\text{ A}\quad(\text{Exact Match }\checkmark)$$
</example>

### 5. Maximum Power Transfer Theorem (MPTT)

#### 5.1 Statement & Step-by-Step Mathematical Derivation

* **Statement:** Maximum DC electrical power is transferred from an active linear bilateral network to a variable resistive load $R_L$ when the load resistance equals the Thevenin internal equivalent resistance of the network as seen from the load terminals:
$$R_L = R_{\text{th}}$$

<derivation title="Maximum Power Transfer Theorem Proof" marks="10 Marks">
1. Reduce the network to its Thevenin equivalent ($V_{\text{th}}$ in series with $R_{\text{th}}$) driving load $R_L$.
2. The load current is:
   $$I_L = \frac{V_{\text{th}}}{R_{\text{th}} + R_L}$$
3. Electrical power delivered to the load:
   $$P_L = I_L^2 R_L = \frac{V_{\text{th}}^2 R_L}{(R_{\text{th}} + R_L)^2}$$
4. For maximum load power with variable $R_L$, differentiate $P_L$ with respect to $R_L$ and set to zero:
   $$\frac{dP_L}{dR_L} = \frac{(R_{\text{th}} + R_L)^2 V_{\text{th}}^2 - V_{\text{th}}^2 R_L \cdot 2(R_{\text{th}} + R_L)}{(R_{\text{th}} + R_L)^4} = 0$$
   $$(R_{\text{th}} + R_L) - 2R_L = 0 \implies R_{\text{th}} - R_L = 0 \implies R_L = R_{\text{th}}$$
5. Substituting $R_L = R_{\text{th}}$ into $P_L$:
   $$P_{\max} = \frac{V_{\text{th}}^2 R_{\text{th}}}{(2 R_{\text{th}})^2} = \frac{V_{\text{th}}^2}{4 R_{\text{th}}}$$
6. **Efficiency at Maximum Power:**
   Total generated power: $P_{\text{gen}} = I_L^2 (R_{\text{th}} + R_L) = 2 I_L^2 R_{\text{th}}$.
   $$\eta = \frac{P_{\text{load}}}{P_{\text{total}}} = \frac{I_L^2 R_{\text{th}}}{2 I_L^2 R_{\text{th}}} = 0.50 = 50\%$$
</derivation>
