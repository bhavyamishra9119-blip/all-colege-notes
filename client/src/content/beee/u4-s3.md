### 5. De Morgan’s Theorems


### 5.1 Statements of Both Theorems

De Morgan’s First Theorem (Complement of a Sum):

> 💡 **Formula: A + B = A · B (for n variables: A + B + C = A · B · C).**

- **Verbal Meaning:** The complement of a logical OR sum equals the logical AND product of the
individual complements.
- **Gate Equivalence:** A NOR gate is logically identical to an AND gate with inverted inputs
(Bubbled-AND).

De Morgan’s Second Theorem (Complement of a Product):

> 💡 **Formula: A · B = A + B (for n variables: A · B · C = A + B + C).**

- **Verbal Meaning:** The complement of a logical AND product equals the logical OR sum of the
individual complements.
- **Gate Equivalence:** A NAND gate is logically identical to an OR gate with inverted inputs
(Bubbled-OR).

expression, break the bar over each variable/group and change every + into · (and every · into +).

- **### 6. Logic Gates:** OR, AND, NOT, NAND, NOR, XOR & XNOR


### 6.1 Classification and Behavior of All 7 Standard Logic Gates

Category A — Basic Gates (Building Blocks of Digital Electronics):

- **### 1. OR Gate:** Output is HIGH (1) if at least one input is HIGH; output is 0 only when all inputs

- **are 0. Expression:** Y = A + B.

- **### 2. AND Gate:** Output is HIGH (1) only when ALL inputs are HIGH simultaneously; if any input

- **is 0, output is 0. Expression:** Y = A · B.

- **### 3. NOT Gate (Inverter):** Single-input gate that outputs the exact logical opposite of its input

- **(0 → 1, 1 → 0). Expression:** Y = A.
Category B — Universal Gates (Can Build ANY Digital Circuit Alone):

- **### 4. NAND Gate (NOT + AND):** Inverted AND gate — output is LOW (0) only when all inputs are

HIGH; otherwise HIGH (1). Expression: Y = A · B.

- **### 5. NOR Gate (NOT + OR):** Inverted OR gate — output is HIGH (1) only when all inputs are

- **LOW; otherwise LOW (0). Expression:** Y = A + B.
Why Called "Universal Gates"? Any basic gate (NOT, AND, OR) and therefore any Boolean
circuit can be built using only NAND gates or only NOR gates:
- **Using NAND only:** Tie both inputs together → NOT; NAND + NAND-NOT → AND; Invert
inputs then NAND → OR.
- **Using NOR only:** Tie both inputs together → NOT; NOR + NOR-NOT → OR; Invert inputs
then NOR → AND.
Category C — Special / Arithmetic Gates:

### 6. XOR Gate (Exclusive-OR / Inequality Detector): Output is HIGH (1) when the two inputs

are different (odd number of 1s); LOW (0) when identical. Expression: Y = A ⊕  B = A·B + A·B.

### 7. XNOR Gate (Exclusive-NOR / Equality Detector / Coincidence Gate): Output is HIGH (1)

when both inputs are equal (0,0 or 1,1); LOW (0) when different. Expression:
Y = A ⊙  B = A ⊕  B = A·B + A·B.
