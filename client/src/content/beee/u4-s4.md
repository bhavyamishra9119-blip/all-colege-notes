### 7. SOP, POS, Canonical Form, Min-Term & Max-Term


#### 7.1 Core Definitions (Starting From Scratch)

**Literal:** A single Boolean variable in either uncomplemented (A) or complemented (A) form.
**Sum of Products (SOP):** A Boolean expression written as the OR sum of two or more AND
product terms.
**Example (Standard SOP):** F = A·B + B·C + A·C (implemented using an AND–OR two-level gate
circuit).
**Product of Sums (POS):** A Boolean expression written as the AND product of two or more OR
sum terms.
**Example (Standard POS):** F = (A + B) · (B + C) · (A + C) (implemented using an OR–AND two-
level gate circuit).
**Canonical (Expanded) Form:** A special form of SOP or POS in which every single term
contains ALL variables of the function (each appearing once, either true or complemented).

#### 7.2 Min-Term (mi) vs. Max-Term (Mi)

Min-Term (mi — Used for Canonical SOP):
A standard product (AND) term containing all n variables that evaluates to 1 for exactly one
input combination.
**Writing Rule:** Variable = 1 → write uncomplemented (A); Variable = 0 → write
complemented (A).
**Shorthand Notation:** F = Σm(…) — collect all rows where output F = 1.
Max-Term (Mi — Used for Canonical POS):
A standard sum (OR) term containing all n variables that evaluates to 0 for exactly one input
combination.
Writing Rule (Exact Opposite of Min-Term!): Variable = 0 → write uncomplemented (A);
Variable = 1 → write complemented (A).
**Shorthand Notation:** F = ΠM(…) — collect all rows where output F = 0.

**Complement Relationship:** Every Max-term is the De Morgan complement of its same-index
**Min-term:** Mi = mi.
**Instant SOP ↔ POS Conversion Rule:** The indices in ΠM are simply the missing indices not
present in Σm (out of 0 to 2n − 1)!

### 8. Karnaugh Maps (K-Maps) up to 4 Variables & Don’t Care Simplification


#### 8.1 Starting From Scratch: What Is a Karnaugh Map?

**Definition:** A systematic graphical grid invented by Maurice Karnaugh (1953) to minimize Boolean
expressions visually without needing error-prone algebraic trial-and-error.
**Number of Cells:** For n input variables, a K-Map contains exactly 2n cells (one cell per
minterm/maxterm):
**2 Variables:** 22 = 4 cells (2 × 2 grid).
**3 Variables:** 23 = 8 cells (2 × 4 grid).
**4 Variables:** 24 = 16 cells (4 × 4 grid).
Why K-Maps Use Gray Code Order (00, 01, 11, 10) — NOT Binary (00, 01, 10, 11):
Notice columns 3 and 4 are swapped (11 comes before 10)!
**Reason:** In Gray code, every pair of physically adjacent cells (including opposite wrap-around
edges) differs in exactly ONE variable — allowing immediate elimination via A·B + A·B = A!

#### 8.2 Step-by-Step Rules for K-Map Simplification (SOP Form)

1. **Step 1 — Fill the Grid:** Place 1 in every cell listed in Σm(…), X in every Don’t Care cell d(…), and
0 in all remaining cells. (For POS minimization, group 0s instead of 1s!)
2. Step 2 — Valid Group Sizes (Strict Powers of 2): Form rectangular or square loops of
16, 8 (Octet), 4 (Quad), 2 (Pair), or 1 (Single) adjacent 1s. Diagonal cells are NEVER adjacent!
3. **Step 3 — Maximize Group Size First:** Always aim for the largest possible group first (an Octet
eliminates 3 variables; a Quad eliminates 2 variables; a Pair eliminates 1 variable).
4. Step 4 — Wrap-Around (Map Rolling) Adjacency: The leftmost column touches the rightmost
column, the top row touches the bottom row, and all four corner cells (m0, m2, m8, m10) form a
valid Quad!

5. Step 5 — Overlapping Is Allowed (Redundancy Is Not): A 1 may be shared by two or more
groups if that makes a group larger, but never add a redundant group whose every 1 is already
covered by other groups.
6. **Step 6 — Read Out Each Simplified Term:** For each loop, drop any variable that changes
between 0 and 1 inside the loop, and keep only variables that stay constant (1 → A, 0 → A). OR
all group terms together.
**Worked 3-Variable K-Map Example:** Minimize F(A, B, C) = Σm(0, 2, 4, 5, 6)
**Plot 1s:** Row A=0 has 1 at m0(00), m2(10); Row A=1 has 1 at m4(00), m5(01), m6(10).
**Group 1 (Wrap-Around Quad:** m0, m2, m4, m6): Leftmost col (BC=00) wraps to rightmost col
(BC=10) → A changes, B changes, only C = 0 stays constant → Term = C.
**Group 2 (Overlapping Pair:** m4, m5): Needed to cover m5 → A = 1, B = 0 stay constant, C
changes → Term = A·B.
**Minimized Result:** F(A, B, C) = C + A·B.

#### 8.3 Don’t Care Conditions (d or X) & 4-Variable K-Map Simplification

What Is a Don’t Care Condition? An input combination whose output can safely be either 0 or 1
— either because that input state can never physically occur (e.g., invalid BCD codes
1010–1111) or because the system ignores the output in that state.
**Notation:** Marked as X (or d) inside the K-Map and written as F = Σm(…) + d(…).
Two Golden Rules for Using Don’t Care (X) Cells:
1. Include an X as 1 ONLY when it expands a group of real 1s into a larger power-of-2 loop (e.g.,
turning a Pair into a Quad or a Quad into an Octet).
2. NEVER form a group consisting solely of Xs — any leftover X that does not help cover a
real 1 is simply treated as 0 and ignored!
Worked 4-Variable K-Map Problem with Don’t Care: Minimize
F(A, B, C, D) = Σm(0, 2, 4, 6, 8, 10, 15) + d(5, 11, 12, 14)
Group 1 (Wrap-Around Octet — Col CD=00 + Col CD=10): Combines real 1s {0, 2, 4, 6, 8, 10}
with Don’t Cares {12, 14} → A, B, C all vary, only D = 0 stays fixed → Term 1 = D.
Group 2 (Bottom-Right Quad — {m15, m14(X), m11(X), m10}): Covers remaining m15 using
Don’t Cares {11, 14} and overlapping m10 → A = 1, C = 1 stay fixed, B, D vary → Term 2 = A·C.
**Ignored Don’t Care:** Cell d(5) does not help enlarge any group of 1s, so it is safely treated as
0!
**Final Minimized Expression:** F(A, B, C, D) = D + A·C (only 3 gates instead of 7!).
